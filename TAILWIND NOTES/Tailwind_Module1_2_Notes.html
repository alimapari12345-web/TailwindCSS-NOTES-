Module 1 — Foundations & Quick Setup

1What Is Tailwind CSS

Tailwind is a utility-first CSS framework. Instead of writing custom CSS rules in a separate file, elements are styled directly in HTML using small, single-purpose classes.

Traditional CSSTailwind
Invent a class name (.btn-primary), then define its styles separatelyApply existing utility classes directly: bg-blue-600 text-white px-5 py-3 rounded-lg
Switch between HTML and CSS files to understand stylingStyling is visible directly in the HTML markup

Tailwind vs Bootstrap

Bootstrap ships pre-built components (.btn, .card, .navbar) that already have a fixed look. Tailwind provides raw utility classes with no built-in look, the design comes entirely from how classes are combined.

  • Every utility class controls exactly one CSS property.
  • bg-blue-600 only sets background color.
  • px-5 only sets horizontal padding.
  • A finished design is built by combining many small classes rather than writing one custom rule.

2CDN Setup

For this course, no Node.js, npm, or build step is required. A single script tag in the page head is enough to enable Tailwind.

<!DOCTYPE html>
<html>
<head>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body>
  <h1 class="text-3xl font-bold text-blue-600">
    It works
  </h1>
</body>
</html>
CDN is for learning, not for shipping: the CDN version compiles Tailwind in the browser on every page load. This is appropriate for practice and prototypes. Production projects use the installed version with a build step, covered in Module 9.

Classes are written inside the normal class="..." attribute, the same attribute already used in plain HTML, just with more values inside it.

3Reading the Syntax

Most Tailwind classes follow the pattern property-value. Recognizing this pattern makes it possible to guess a class before checking documentation.

PrefixProperty it controlsExample
bg-Background colorbg-red-500
text-Text color or font size (context-dependent)text-white / text-xl
p-Padding, all sidesp-4
m-Margin, all sidesm-2
rounded-Border radiusrounded-lg
font-Font weight or familyfont-bold
w- / h-Width / heightw-64
Guessing approach: identify the CSS property being targeted, then shorten it. Font size needs text- plus a size word. Background color needs bg- plus a color. The Tailwind documentation search bar accepts CSS property names directly and returns the matching class.

?Module 1 — Common Questions & Misconceptions

MythTailwind is just inline styles with extra steps.
Inline styles cannot respond to hover, focus, dark mode, or screen size. Tailwind classes can, through variants like hover:bg-blue-700, md:text-xl, and dark:bg-slate-900. Tailwind also enforces shared design tokens (spacing, colors) across a project, which raw inline styles do not.
MythHundreds of classes must be memorized before starting.
Only the property-value pattern and a handful of prefixes need to be learned upfront. Most other classes are guessable from the pattern, and the rest are one documentation search away.
Q&AIs Node.js or npm required to follow this course?
No. The CDN script tag provides full Tailwind functionality in the browser with no installation. The installed build version is introduced later, in Module 9.
Q&AWhat happens if a class is misspelled, such as bg-blu-600?
Nothing breaks. Tailwind does not recognize the class, so no style is applied for that property, and no error message appears with the CDN version. Careful spelling matters more than it would with a compiler that reports errors.
MythUtility classes make HTML unreadable.
This looks unfamiliar at first, but long class lists are commonly considered easier to scan than switching between an HTML file and a separate CSS file to trace what styles an element. Familiarity with reading class lists develops quickly with regular use.
Q&ACan custom CSS still be written alongside Tailwind?
Yes. Tailwind does not replace CSS, it is built on top of it. A style block or external stylesheet can still be used for anything Tailwind does not cover.
Module 2 — Typography & Color

1Text Utilities

Font size uses named steps rather than pixel values. Weight and alignment use their own separate prefixes.

CategoryClasses
Size scaletext-xs through text-9xl. text-base is the default (16px). text-xl is 20px. text-4xl is 36px.
Weightfont-thin (100), font-normal (400), font-semibold (600), font-bold (700), font-black (900)
Alignmenttext-left, text-center, text-right, text-justify
Otheritalic, underline, uppercase

2Leading & Tracking

leading-* controls line height, the space between lines of wrapped text. tracking-* controls letter spacing, the space between individual characters. These control different axes and are not interchangeable.

ClassEffect
leading-noneTightest line height
leading-normalDefault line height
leading-looseWidest line height
tracking-tighterLetters pulled closer together
tracking-wide / tracking-widestLetters spaced further apart
Common trap: leading only becomes visible once text wraps onto multiple lines. Applying it to a single short word produces no visible change, this is expected behavior, not a bug.

4The 50-950 Shade Scale

Every color in Tailwind comes in 11 shades, numbered 50 (lightest) to 950 (darkest). 500 is roughly the "true" version of that color.

50

400
500
600
700
800
900
950

This is the green palette. Every other color name (blue, rose, slate, amber) follows the same 11-step structure.

Rule of thumb: shades 50-300 work as backgrounds and subtle fills. 400-600 are the main usable colors for buttons and links. 700-950 work as dark text or dark-mode backgrounds. Starting at 500 and adjusting up or down is a reasonable default approach.

?Module 2 — Common Questions & Misconceptions

Mythtext-lg always means the same pixel size across every project.
It means the same size relative to Tailwind's default scale (18px for text-lg out of the box), but a project's tailwind.config.js can redefine the scale. For this course's default setup, the standard sizes apply consistently.
Myth500 is always the exact middle brightness of a color.
This holds for most palettes, but a few colors, such as yellow, appear visually brighter at 400 than at 500 due to how the human eye perceives that hue. Checking a shade visually is more reliable than assuming the number guarantees a specific brightness.
Q&AWhy does text-white disappear when the background changes from bg-sky-500 to bg-sky-100?
This is expected. Light backgrounds (50-300 range) need dark text for readable contrast, while darker backgrounds (500 and above) generally need light text. This is also a real accessibility consideration in production work.
Q&AWhat does the /50 in a class like text-red-500/50 mean?
The slash sets opacity, in this case 50 percent. This is separate from the shade number before it. A slash followed by a number after a color class indicates opacity, not an additional shade step.
MythLeading and tracking are two names for the same thing.
They control different axes. Leading is vertical space between lines. Tracking is horizontal space between letters. Confusing the two is a frequent early error, if lines feel cramped, leading is the relevant property, not tracking.
Q&ACan font size and color classes be combined freely?
Yes, they control independent CSS properties, so classes like text-4xl text-blue-600 font-bold combine without conflict. Conflicts only occur when two classes try to set the same property, such as two different text size classes on the same element, in which case whichever appears later in the compiled stylesheet takes effect. Avoiding duplicate prefixes on one element prevents this issue entirely.

✓Summary

  • Tailwind is utility-first: one class, one CSS property, applied directly in HTML.
  • The CDN script tag is sufficient for learning, no installation required.
  • Most classes follow the pattern property-value, which makes many classes guessable.
  • Text size uses a named scale (text-sm to text-9xl), not raw pixel values.
  • Leading controls line height, tracking controls letter spacing, they are not interchangeable.
  • Color classes follow property-color-shade, with 11 shades from 50 to 950 for every color.
