1Display Types

The display property decides how an element behaves in the page layout: whether it takes a full line, sits inline with text, or becomes a container that arranges its children.

ClassEffect
blockTakes up the full width available, always starts on a new line
inline-blockSits inline with surrounding content, but still accepts width/height/padding
hiddenRemoves the element from the page entirely (no space reserved)
flexTurns the element into a flex container, arranging its direct children in a row by default
Key distinction: a plain inline element (like a default <span>) ignores width and height. inline-block exists specifically to keep inline positioning while still allowing size control.

2Flex Container Setup

Adding flex to an element does two things at once: it makes that element a flex container, and it automatically arranges its direct children into a row, side by side, with no extra class needed for the row itself.

<div class="flex bg-slate-800 p-4 gap-4">
  <div class="bg-sky-500 p-4">One</div>
  <div class="bg-sky-500 p-4">Two</div>
  <div class="bg-sky-500 p-4">Three</div>
</div>

Important: flex only affects the direct children of the element it's applied to. Grandchildren nested further inside are not automatically arranged, they follow their own parent's rules.

3Flex Direction

By default, a flex container arranges children in a row. This can be switched to a column.

ClassEffect
flex-rowChildren arranged left to right (this is the default, so writing it explicitly is optional)
flex-colChildren arranged top to bottom

Key point: direction changes which axis is "main" and which is "cross." In a row, main axis is horizontal. In a column, main axis is vertical. This directly changes what justify-* and items-* do, covered next.

5Align Items (Cross Axis)

items-* controls alignment along the cross axis — the axis perpendicular to the main one. In a row, this means vertical alignment.

ClassEffect
items-startChildren align to the top of the container
items-centerChildren align to the vertical center
items-endChildren align to the bottom
items-center (in a row, taller container)
Short
Taller
Most common confusion in this module: justify-* and items-* are not interchangeable and do not always mean "horizontal" and "vertical." Their meaning flips depending on flex-direction. In a row, justify is horizontal and items is vertical. In a column, this reverses, justify becomes vertical and items becomes horizontal.

6Growth, Gap & Wrap

flex-1

flex-1 tells a child to grow and fill any remaining space in the container, shared equally with any other child that also has flex-1.

<div class="flex gap-4">
  <div class="flex-1 bg-sky-500 p-4">Grows</div>
  <div class="bg-slate-600 p-4">Fixed</div>
</div>

In this example, the second box stays at its natural content width, and the first box expands to take up all remaining space.

gap

gap-* adds space between flex children, using the same spacing scale as padding and margin. This is different from margin because it does not add space outside the entire container, only between the items inside it.

flex-wrap

By default, flex children are forced onto a single line and will shrink to fit. flex-wrap allows children to move onto multiple lines once they run out of horizontal space.

ClassEffect
flex-nowrapDefault. All children forced onto one line, shrinking if needed
flex-wrapChildren move to a new line once space runs out

?Common Questions & Misconceptions

Mythjustify-* always means horizontal alignment.
Incorrect. justify-* controls the main axis, which is horizontal by default (flex-row) but becomes vertical if flex-col is applied. Always check the direction first.
Q&AWhy don't my grandchildren elements line up when I add flex to the outer parent?
flex only arranges direct children. Elements nested two or more levels deep are unaffected unless their own immediate parent also has flex applied.
MythYou need flex-row to make children appear in a row.
Not necessary. Row is the default direction the moment flex is applied. flex-row only needs to be written explicitly if overriding a column direction back to a row, such as at a specific breakpoint.
Q&AWhat's the difference between gap and margin for spacing flex children?
gap only adds space between items, not around the outer edge of the container. Margin on individual children adds space around that specific child, which can create uneven or doubled-up spacing between neighbors.
Q&AWhy do my flex items shrink and squeeze together instead of wrapping to a new line?
This is default behavior. flex-nowrap is implied unless flex-wrap is explicitly added, so items are forced to fit on one line and shrink rather than move down.
Mythflex-1 makes an element take up the full container width by itself.
flex-1 makes an element grow to fill remaining space, shared with any sibling that also has flex-1. If only one child has it and others have fixed sizes, flex-1 fills whatever space is left over, not the entire container.

✓Summary

  • flex turns an element into a flex container and arranges direct children in a row by default.
  • flex-row / flex-col set the direction, which decides which axis is "main" and which is "cross."
  • justify-* controls the main axis. items-* controls the cross axis. Their real-world direction depends on flex-direction.
  • flex-1 grows an item to fill remaining space, shared among any siblings with the same class.
  • gap-* spaces items apart without adding space around the outer container edge.
  • flex-wrap allows children to move onto new lines once space runs out; without it, items shrink to fit one line.
